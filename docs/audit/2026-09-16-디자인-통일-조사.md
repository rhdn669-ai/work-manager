## 7. 고칠 순서 제안

### 1단계 — 뿌리 (이걸 먼저 안 하면 재작업)
1. `--space-*` 토큰을 4배수로 재정의 · `--radius-*` 를 문서와 싱크
2. 버튼 토큰 3종 고정 (높이 36/30/24 · 라운드 7px/999px/50%)
3. 표 정렬 규칙 하나 — 숫자 오른쪽 · 글자 왼쪽 · 작업 칸 오른쪽

### 2단계 — 한 번에 치환 가능 (기계적)
4. 숫자 열 인라인 style → `col-num` · `num-col` 오탈자 → `col-num` · `u-num` → `col-num`
5. 삭제 버튼 7곳 표준화 · `×`·`＋` 리터럴 → Icon
6. 빈 화면 19곳 → `EmptyState`
7. `.card` 죽은 줄 삭제 · quality.css `col-action` 재정의 삭제 · `.revenue-card-head` position:relative
8. 인접형제 margin → `.btn-group` / 부모 gap
9. 카드 body padding 16px 통일 (지금 6종, 표준과 맞는 곳 0)
10. 토스트 마침표·「…」 표기 통일

### 3단계 — 화면을 보며 (하나씩)
11. **1340px 폭 예산** — 생산현황(4,746) · 구매처 표(2,103) · BOM 상세(1,758) · 품목 표(1,519) · 휴지통 탭(1,565). 열을 접거나 합치거나 드롭다운으로
12. 헤더 버튼 5개 한 줄 정렬
13. 칸반 카드 제목 2줄 허용
14. 잘린 칸 폭 조정 (호기 태그 · 가능 SET · 금액 · 캘린더 칩 · 읽기전용 입력칸)

16. native select 3곳 · MarginClosingPage 금액 입력 3중 구현 · PC 표 없는 3개 화면
17. `chat-*` 죽은 CSS 확인 후 삭제 · `PurchaseHubPage.jsx` 삭제
